# Локальная подложка HUD

Дата: 2026-10-09 (продолжение задачи от 8 октября).
Метод: процедурный PIL/NumPy, не image_gen.
Файл: [backing.png](backing.png).
Генератор: [gen_hud_skin.py](../../../tools/art/gen_hud_skin.py).

Дымчатый navy RGB12,22,34. Рабочий центр alpha204/255 (0.8), только короткие края плавно исчезают. Размер512x128. Применяется локально за текстом и предметными/неактивными панелями; пространство между тремя кластерами открыто. Исходные семь image_gen glyphs не изменены.
