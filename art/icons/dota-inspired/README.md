# Иконки магазина - 7 октября 2026

Пользователь выбрал preview в духе Dota 2 и разрешил заменить игровые иконки. Новые рисунки созданы встроенным imagegen по выбранному листу `style-reference.png`. Это собственные изображения предметов, не извлеченные игровые ассеты Valve. Названия и механики существующего каталога здесь не меняются.

## Источники и сборка

- `primary.png`: 12 x 5, 60 рисунков (5 расходуемых и 55 готовых вещей).
- `support.png`: 8 x 6, 48 рисунков (26 компонентов, 17 расходуемых и 5 готовых вещей).
- `advanced.png`: 7 x 4, 26 готовых вещей, служебный значок рецепта в ячейке 26, пустая ячейка 27. Индексы начинаются с нуля.
- Промпты сохранены рядом в `*.prompt.txt`. Размеры в промптах - запрос генератору; импорт использует фактические размеры PNG и пропорциональные границы сетки.
- `../../../tools/art/dota-style-manifest.json` фиксирует соответствие ячеек 134 рисункам, 13 производных вариантов и 86 рецептам. Все 233 ID покрыты ровно один раз. Витрина рецептов использует ID готового результата, а рецепт в рюкзаке - собственный ID с печатью.

Хеш каталога проверяется после нормализации UTF-8 и окончаний строк в LF, чтобы настройки Git CRLF не влияли на импорт. Хеши PNG и Unity metadata проверяются по исходным байтам.

Подготовка ресурсов выполняется `tools/art/import_dota_icons.ps1` через штатный Windows PowerShell 5.1 и System.Drawing. Предметы кодом не рисуются: выполняются нарезка регулярного атласа, экспорт PNG 128 x 128 RGBA и служебные метки уровней/рецептов. Существующие имена и `.png.meta` сохраняются.

Из корня репозитория:

```powershell
powershell.exe -NoProfile -File tools/art/import_dota_icons.ps1 -ValidateOnly
powershell.exe -NoProfile -File tools/art/import_dota_icons.ps1
powershell.exe -NoProfile -File tools/art/import_dota_icons.ps1 -Apply
```

По умолчанию создается только staging в `.local/art/dota-icons-staging`. `-Apply` проверяет и сохраняет текущие PNG и meta в `.local/art/dota-icons-before/png`, заменяет только PNG и сверяет hashes. Отличающаяся существующая резервная копия не перезаписывается; для последующих применений выберите отдельный `-BackupDirectory` внутри `.local/art`. Перед обновлением Unity убедитесь, что Editor не выполняет другую операцию. `GameArenaBuilder.Build()` для этих иконок не нужен.

`tools/art/gen_icons.py` - исторический локальный источник форм и параметров. Он не входит в этот коммит и не требуется для импорта нового набора: параметры сохранены в manifest, а изображения - в атласах. Для принятого рисованного набора используйте импорт новых источников.

Скриншоты и 6 HUD-тестов получены в текущем рабочем дереве с новым меню. Код меню и остальных параллельных изменений не входит в этот ассетный коммит; сам по себе он добавляет набор иконок и воспроизводимый импорт, а не новую витрину.
