# game

Проект самостоятельной игры, вдохновлённой «Жизнью на арене» из Warcraft III и Dota 2. Исследование этих кастомных игр служит материалом для анализа механик и спроса. Название, код, ассеты и брендинг будущей игры должны быть собственными или использоваться с проверенными правами.

Рабочая папка существующего проекта: `C:\Users\Netes\Desktop\proj\game`. Не создавайте второй проект `game` в другом месте. Инициализация и проверка Unity, Blender и доступа Codex выполняются в этой папке; фактические результаты, версии и ограничения смотрите в [docs/setup.md](docs/setup.md). Наличие документа или MCP-конфига само по себе не подтверждает рабочее подключение.

Для текущего этапа выбраны **Unity и Blender**, с управлением через код, CLI, API и MCP. Пользователь предпочитает не разрабатывать игру кликами по редактору. UI допустим для необходимой настройки. Пока не утверждены MVP, сетевой режим, длительность сессии, монетизация, окончательная платформа, точная проекция камеры и артстиль.
