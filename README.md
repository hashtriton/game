# game

**Локальная Windows-сборка готова к запуску и проверке.** На этом ПК архив находится в `builds/Arena-Windows-2026-10-06-rules10.zip`, приложение - в `builds/windows/Arena.exe`. Эти бинарные файлы не входят в Git. Локальный архив нужно распаковать целиком и запустить `Arena.exe`. Из клона репозитория запускайте проект `unity` в Unity Editor по [инструкции настройки](docs/setup.md). Выберите героя и нажмите «Играть одному». Для совместной игры используются отдельные кнопки создания сервера, подключения и готовности. [Управление и запуск](docs/playing.md), [проверки и ограничения](docs/lia39-overnight-progress.md).

Сборка содержит арену по планировке Life in Arena 3.9c, 30 волн, предметы и рецепты, прокачку и способности, дуэли, боссов и совместную игру. Доступны Рыцарь, Эльфийская Лучница и Пиромант; клановые режимы исключены, модели пока используются существующие бесплатные. Интерфейс обновлен с применением запрошенного `ui-ux-pro-max`. Версии сетевого контракта и правил: protocol 17 / `lia39-unity-rules-10`.

Проверено в Unity: полный Original 1426/1426, после последней правки AI - затронутые 32/32, итоговый PlayMode 26/26. Windows-приложение запускалось в двух отдельных процессах с матчем через `127.0.0.1:17739`; проверены покупка, расход маны навыка, отметка приказа движения, меню и возврат в лобби. Контролируемые Standard и Nightmare достигли финала 30-й волны с неуязвимостью и служебным завершением боев. Обычное прохождение всех 30 волн, соединение двух физических ПК и полное совпадение частных правил движка Warcraft не подтверждены.

Для работы в редакторе откройте сцену `unity/Assets/Arena/Scenes/Lia39Arena.unity` и включите Play. В сборку не входят исходная карта Warcraft или ее модели, текстуры и звуки; лицензии используемых ресурсов находятся в папке `Licenses` рядом с приложением. ZIP содержит `Build-info.json` с происхождением сборки.

Проект самостоятельной игры, вдохновлённой «Жизнью на арене» из Warcraft III и Dota 2. Исследование этих кастомных игр служит материалом для анализа механик и спроса. Название, код, ассеты и брендинг будущей игры должны быть собственными или использоваться с проверенными правами.

Рабочая папка существующего проекта: `C:\Users\Netes\Desktop\proj\game`. Не создавайте второй проект `game` в другом месте. Инициализация и проверка Unity, Blender и доступа Codex выполняются в этой папке; фактические результаты, версии и ограничения смотрите в [docs/setup.md](docs/setup.md). Наличие документа или MCP-конфига само по себе не подтверждает рабочее подключение.

Для текущего этапа выбраны **Unity и Blender**, с управлением через код, CLI, API и MCP. Текущий разрешенный объем: перенос механик 3.9c, три героя (Рыцарь, Эльфийская Лучница и Пиромант), совместная игра без кланов и современный интерфейс. Новые модели отложены. Монетизация и публичный релиз не утверждены.

5 октября 2026 года выбрано **современное стилизованное 3D-фэнтези с корнями в Warcraft**. Герои, объекты и существа будут собственными, новыми, крутыми, современными и стильными. Конкретные дизайны ещё предстоит создать; контент Warcraft не копируем. Актуальный художественный курс - в [docs/art-direction.md](docs/art-direction.md).

## Начать работу в Codex

Откройте в боковой панели локальный проект **Game** и задачу **«Проверить стек Game»**. В этой сессии нативные MCP Unity/Blender уже обнаружены, Unity read проверен. Unity проект находится в `unity/`; Blender CLI не требует открытого GUI. Передайте этой задаче следующий конкретный шаг по прототипу: контекст она читает из документов репозитория. Каждый Blender Python вызов согласовывается отдельно; фактический автоматический диалог в этой сессии ещё не проверен. Подробный запуск, версии, проверки и локальная Windows поправка Blender MCP описаны в [docs/setup.md](docs/setup.md).
