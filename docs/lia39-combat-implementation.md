# Реализация боя LiA 3.9c

Срез 2026-10-06. Эта матрица описывает исполняемый host-код и проверенные границы. Она не подтверждает органическое прохождение всех 30 волн, текущую Windows-сборку или полное совпадение с Warcraft. Предметная матрица ведётся отдельно в [lia39-item-implementation.md](lia39-item-implementation.md). Исторические общие прогоны находятся в [lia39-port-status.md](lia39-port-status.md).

Источник: `Life_in_Arena_v3_9_c.w3x`, SHA256 `02a7901230963386347df738e292e4a0bc6dbfd47d062d502986ec88f0bbea34`; script SHA256 `8af410dad5ccf8c5dbf718e9fdace81d60add0176578548afc673baff6366389`. Локальные исходники: `.local/research/lia/warcraft/3.9c/extracted/scripts/war3map.j`, таблицы `Units/AbilityData.slk` и `UnitBalance.slk`, производный каталог `unity/Assets/Arena/Data/lia39-combat.json`. Нативные измерения относятся к локальному Warcraft 1.26.0.6401. Каждый `tools/arena/extract_observed_*.py` проверяет identity, исходные SHA/CRC, контрольные строки и границы собственного измерения.

## Уровни доказательства

- **Runtime**: конкретная ось поведения воспроизведена нативным измерением. Это не переносит доказательство на все параметры, rawcode или сочетания семейства.
- **Declaration / static-path**: числовое поле или исполняемая ветвь исходного JASS. Тест C# проверяет наш перенос, а не работу закрытого движка.
- **Derived**: явно выбранная политика host: RNG, порядок перечисления, поиск места, фаза сканирования, совместное действие неизмеренных эффектов.
- **Unimplemented**: игрокозаметный эффект пока отсутствует. Такие строки ниже не считаются завершёнными по наличию записи в каталоге.

## Игрокозаметные незакрытые механики

1. **Обычный боевой путь текущих трёх героев и волн**: известного общего RuleUnavailable/halt в описанных семействах не осталось. Все18 ordinary active families, шесть wave scripts, A11G, точный A0O1 helper связей A1DD/A1DI и публичный I07C имеют исполняемые drivers. Это не утверждение о полной engine parity всех сочетаний или ещё проверяемых предметных активов.
2. **Неизмеренные сочетания**: native command queue, status pause/refresh/stacking, invisibility/detection interactions, projectile private geometry и общий RNG. Известные эффекты работают с явно названными host policies; эти границы не заменяются скрытыми нулями.
3. **Sparse numeric axes**: A0O1 rank1 закрыт отдельным Probe93: дополнительные HP-потери0, два callback0, BPSE3s. DataA2/3/4 не подставлялись вместо отсутствующего DataA1. Для AEev A11I/A11D/A11E/A11K/A11J INDEF2 подтвердил по64 положительных попадания в64 полных интервалах с unpaused hfoo; INDEF1 отдельно дал такой же результат с paused target. Это не доказывает вероятность0. Поле остаётся unknown, новая вероятность не выдумана, матч не блокируется. Прежний A059 armor gap для I029/I05D закрыт ITEMSTAT2: scoped rank1 intrinsic0 после вычитания известных других5/8armor; это не заполняет отсутствующее static поле для всех контекстов.
4. **Шесть вторичных orb effects исполняются**: AIob у I01N/I0B0 (A062) и I03N (A0BJ), AIfb у I02A (A07K) и I02C/I0A6 (A08B). `ItemOrbSecondary` захватывается при release, frost применяется основной цели, fire наносит отдельные15/75 в radius180 до основной атаки, включая Amim и hero12/60; missed/evasion исключают оба эффекта, secondary damage не создаёт рекурсивный splash. ITEMORB2 и portable8/8 повторены независимо; точные native edge/stacking/priority/pause/refresh и перенос sibling items остаются явно ограниченными. Все7 item summons используют общий бой, включая weapon2/msplash; ward point-target UI и native mana-aura cadence имеют отдельные ограничения.
5. **Визуальное состояние native statuses**: числовые эффекты Aply/roots/Shadow/Purge работают; отдельные формы моделей и родные status FX не подтверждены этой матрицей.
6. **Полный матч и выпуск**: органический бой с покупками и сетевыми игроками, современный UI и Windows build требуют финальной проверки root. Portable suites и управляемые boss fixtures не заменяют её.
