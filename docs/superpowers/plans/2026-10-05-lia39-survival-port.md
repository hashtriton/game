# Перенос Survival 3.9c - план реализации

**Goal:** повторить игровой процесс локальной Warcraft Life in Arena 3.9c в Unity с существующими моделями, сетевым совместным прохождением и тремя исходными героями.

**Architecture:** отдельное ядро исходных правил и каталогов, явные игровые события и проверяемые переходы состояния. Unity отвечает за представление и ввод; ведущий сетевой сессии владеет состоянием матча. Неизвестный эффект не заменяется выдуманным действием.

**Tech Stack:** Unity 6000.6.4f1, C#, URP 17.6.0, Input System, Python 3 для воспроизводимого извлечения.

**Spec:** текущие поручения пользователя; источник `.local/research/lia/warcraft/Life_in_Arena_v3_9_c.w3x`, SHA256 `02a7901230963386347df738e292e4a0bc6dbfd47d062d502986ec88f0bbea34`; правила происхождения данных в `docs/lia-data-use.md`.

## Ограничения

- Только 3.9c. Клановые режимы исключены пользователем, сетевой Survival включен.
- Три героя вместо 96: Рыцарь `H008`, Эльфийская Лучница `N0A0`, Пиромант `H024` (выбор подтвержден пользователем). Все остальные запрошенные системы остаются в области работ.
- Новые модели не создавать. Для разных крипов допустима одна существующая модель.
- Удалить из игрового пути прежние пять придуманных волн, универсальные Q/рывок и выбор трех усилений.
- Проверенный исследовательский набор не менять. Новые преобразования находятся в `tools/arena/`, данные Unity в `Assets/Arena/Data/`.
- Не копировать исполняемый JASS или исходную графику в Unity. Каждое перенесенное правило имеет ID и source line/offset.
- Warcraft 1.26 предоставлен пользователем и запущен локально; карта3.9c загружается. Выборочная runtime-сверка начата, полное прохождение пока не выполнено.
- Предыдущий commit/push завершен; новое поручение разрешает реализацию, но не новый commit/push.
- Базовый commit `9dfac6ce2caa0b5cca23c9bdf238c6ef39cda34e`; чужие staged art/scorpion файлы сохраняются. Повторный pull в грязное дерево не выполняется.

## Проверка рисков

- Пустое исходное поле и конфликт profiles не должны превращаться в выбранное по памяти число.
- Волны 21/23 учитывают потомков; их начальное число не равно счетчику завершения.
- Повтор после гибели команды не выдает повторно награду завершенного этапа.
- Инвентарь героя и прислужника, повторные компоненты и заряды проверяются вместе.
- Клиент не назначает себе предметы, урон, награду или позицию; повторные/невалидные сетевые команды отклоняются ведущим.
